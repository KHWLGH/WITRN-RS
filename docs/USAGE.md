## 界面总览

窗口分三层：**标题栏**（Tab + 设备连接）、**工作区**（当前 Tab 的内容）、**状态栏**。

### 标题栏

标题栏同时承担 Tab 条的职责，常显监控、PD 分析和设置；连接 POWER-Z 后增加协议控制入口：

| Tab | 内容 |
| --- | --- |
| `监控` | 实时读数、图表、记录与导入导出 |
| `PD 分析` | USB-PD 报文列表与逐字段解码 |
| `协议控制`（仅 POWER-Z） | PDM、PDO、协议检测与电压触发 |
| `设置`（齿轮图标） | 外观、图表与记录、设备 VID/PID/SN、关于 |

右侧是**常驻的设备连接区**：设备下拉框、刷新按钮，以及一颗随状态切换的 `连接` / `断开` 按钮。因为它在标题栏上，所以在任何 Tab 都能连断设备，不需要先切回监控页。未连接时显示 `连接`，已连接后同一颗按钮变成 `断开`。

设备下拉框里的名称格式为：

```
WITRN K2                                    未能解析 USB 端口时
WITRN K2 (USB 4-4)                          解析出 USB 拓扑端口
WITRN K2 (USB 4-4) [接口 0 / Usage 0xFF00]   同一物理设备有多个 HID 接口时
```

接口后缀只在同一物理设备筛选后仍剩多个 HID 接口时才出现。未识别 PID 的维简设备显示为 `未知 WITRN 设备 (0716:XXXX)`。

### 状态栏

底部状态栏常显：`记录:`（当前记录状态，**可点击**以开始或暂停记录）、`时长:`（当前记录累计时长）、`采样:`（当前采样率）、`点数:`（已采集的数据点总数），以及右侧的连接状态指示（`已连接` / `未连接`）。未连接时点击 `记录:` 不会开始记录。

## 监控工作区

### 命令栏

| 控件 | 说明 |
| --- | --- |
| `开始记录` / `继续记录` / `暂停记录` | 启停记录。按钮文案随状态变化：无数据时为 `开始记录`；已有数据（含导入的数据）时为 `继续记录`，续接当前时间线且不清空已有数据；记录中为 `暂停记录` |
| `采样率` | 下拉选择，见下表 |
| `导出CSV` | 下拉菜单：`不带温度` / `带温度`。命令栏变窄时与导入、一键重置一并收进右侧 `⋯` 溢出菜单 |
| `导入CSV` | 读入此前导出的 CSV，导入后可从最后一个时间点继续记录 |
| `一键重置` | 清空图表并重置统计与累计能量 |
| `⋯` | 宽度不足时出现，内含导出 / 导入 / 一键重置 |
| `显示` | 打开通道显示浮出面板 |
| `自动暂停` | 开关 + 齿轮打开配置浮出面板 |
| `温度服务` | 开关 + 齿轮打开配置浮出面板，详见 [外部温度服务](TEMPERATURE.md) |

采样率下拉的预设（括号内是实际的毫秒间隔，也是 CSV 里 `SampTime(ms)` 的值）：

| 显示 | 间隔 |
| --- | --- |
| `100 次/秒` | 10 ms |
| `10 次/秒` | 100 ms |
| `4 次/秒` | 250 ms（默认） |
| `2 次/秒` | 500 ms |
| `1 次/秒` | 1000 ms |
| `0.2 次/秒 (5秒1次)` | 5000 ms |
| `0.1 次/秒 (10秒1次)` | 10000 ms |

选中 POWER-Z KM003C / KM002C 时会额外显示 `1000 次/秒`（1 ms）。该模式使用设备的
AdcQueue，样本带 1 kHz 设备时基；温度由并行 ADC 快照补齐。认证或设备固件不支持高速队列时，
应用会自动退回 `100 次/秒` 并提示原因。维简 HID 设备始终使用不小于 10 ms 的间隔。

后端 `set_sample_rate` 接受 1 – 60000 ms 的任意值，具体下限由设备决定。导入 CSV 使用文件中的逐点间隔、摘要间隔或时间序列估算，不覆盖持久化的采样率设置；下拉框仍显示下一次实时采集的间隔。

采样率同时决定**累计能量忽略多大的空档**：相邻两点间隔超过 `max(2 秒, 8 × 采样间隔)` 时那一段不计入积分（休眠、NTP 校时、漏采都属于这一类）。所以在 `0.2 次/秒` / `0.1 次/秒` 这类慢档下，空档容忍会跟着放宽到 40 秒 / 80 秒，而不是把每一步都当成空洞。

### 读数卡片

左栏默认可拖宽度（200–360 px，默认 250 px），右侧分栏条拖动后宽度会写入配置。四张主卡（电压 / 电流 / 功率 / 温度）结构统一：

- 标题：通道色圆点 + 名称；
- 下方圆角 **横向电平条**只包住当前读数：底色与填充为同一通道不同色度（底更淡、电平更饱和）；量程按会话观察最大值自动取 1-2-5，填充从左向右；大字读数居中并占满条的大部分，文字用常规文本色；
- 三列统计：`最小` / `平均` / `最大`（温度卡为 `最低` / `平均` / `最高`）。

其余卡片：

- **电流** —— 启用「记录电流方向」时数值前方显示方向箭头。
- **温度** —— 无温度源时整张卡隐藏，数值显示 `--`。来源为 `本机` 时温度随仪表一起消失：断开或拔出仪表即注销该温度源（读数回 `--`、`温度服务` 按钮复位、`来源` 重新可选）；来源为 `外部` 的 TCP 会话独立，不受仪表连接状态影响。
- **累计能量 (Wh)** 与 **累计容量 (mAh)** —— 由软件对采样点积分得出，不是仪表内部的累加器。每行配一条水平迷你条（同样走自动量程）。**只有 `一键重置` 会把它们归零**；暂停后继续记录时累计值保留，且暂停期间的时长不计入积分。间隔超过 `max(2 秒, 8 × 采样间隔)` 的空档同样不计入（见上文采样率一节）。
- **信号线** —— D+ / D- / CC1 / CC2 四路电压，每格名称 + 数值，下方一条水平迷你条。显示保留两位小数，实际分辨率取决于设备；WITRN CC1 / CC2 为 0.1 V。

图表无数据时，图表区域叠一层空状态：「连接设备后点击开始记录」。开始记录并写入第一个点后消失。

### `显示` 浮出面板

- 四条主曲线 `电压` / `电流` / `功率` / `温度` 各有一个显隐勾选框和一个**填充不透明度**输入（0 = 关闭填充，1–100 = 开启填充，默认 15）。
- `D+ / D-` —— 在图表中叠加两条信号线曲线，复用电压坐标轴。默认关闭。
- `CC1 / CC2` —— 同上，复用电压坐标轴。默认关闭。
- `仅统计选中范围` —— 勾选后，读数卡上的最小 / 最大 / 平均以及累计能量、容量都只统计时间线导航器当前选中的范围。默认关闭。非有限的样本值（导入的 CSV 里空着或写成 `NaN` / `Inf` 的那些）不参与最小 / 最大 / 平均，均值旁会以 tooltip 说明被排除的点数；`范围` 标签里的「(N点)」仍是选中区间的原始行数，不是参与计算的点数。

### `自动暂停` 浮出面板

用于无人值守测试：当被测量持续低于阈值一段时间后自动停止记录。

| 字段 | 取值 |
| --- | --- |
| `条件` | `无`（默认，即关闭） / `电压 <` / `电流 <` / `功率 <` |
| `阈值` | 数值，单位随所选条件自动切换 |
| `持续时间` | 秒。必须连续满足条件这么久才触发 |

### 图表与时间线

主图最多同时绘制 8 条曲线，共用 4 条 Y 轴：**电流 (A)**、**电压 (V)**、**功率 (W)**、**温度 (°C)**，四轴刻度严格共线。D+ / D− / CC1 / CC2 复用电压轴。

- **tooltip** —— 悬停显示该时刻全部通道的数值和相对时间（`HH:MM:SS.d`）。
- **图例** —— 点击通道名可临时隐藏该曲线。
- **时间线导航器** —— 底部缩略图，拖动两端手柄选取范围，拖动中间高亮选区可平移窗口（跨度不变）；中间显示 `时长:` 与该范围的点数。
- **滚轮横向缩放** —— 在主图上滚动，以光标所在时刻为锚缩放时间窗。向上/向前拉近，向下/向后拉远。录制中同样可用：窗口右沿贴着最新点时跟最新走（时长不变），看历史时则定住该片段。滑块会跟着动；暂停后再继续记录不会丢掉当前窗口。
- 密集数据自动切换为增量 min/max 像素桶渲染，完整数据仍保留在列式存储里；悬停时二分回查原始采样点，读到的是真实值而非降采样值。回看按画布的实际像素分辨率保留曲线细节，高 DPI 下也不会用宽桶替代精细曲线；拖动中和松手后采用相同投影，放大到每个画布像素不超过一个采样点时恢复原始点及窗口两侧邻点。

1000 次/秒采样时，曲线自动刷新默认约 20 帧/秒，绘制压力较高时可降至约 10 帧/秒；拖动手柄、平移选区、滚轮缩放和键盘调整会独立刷新，松手后提交最终窗口。100 次/秒的健康绘图不会因历史变长固定降刷新率。刷新频率只影响曲线显示，全部采样点、CSV、统计和能量积分仍完整保留。录制预算与回看预算独立；回看慢帧可暂时关闭面积填充并采用像素列绘制，曲线精细度保持不变。

## PD 分析工作区

### 命令栏

| 控件 | 说明 |
| --- | --- |
| `开始记录` / `暂停` | 启停 PD 报文采集 |
| `清空` | 清空报文列表 |
| `导出` / `导入` | PD 捕获的 JSON 存取 |
| `按消息类型过滤…` | 文本输入，按消息类型名过滤列表 |
| `隐藏 GoodCRC` | GoodCRC 是链路层确认帧，数量通常占一半以上，隐藏后列表可读性大幅提升 |
| `自动滚动` | 出现新报文时自动滚动到底部 |
| `跟随记录` | 与主监控联动，见下 |
| 分栏方向 | 宽屏（窗口宽度 ≥ 1400px）时可改为左右分栏（列表约 55% / 详情约 45%）；偏好会保存，窄窗口仍回到上下布局 |

命令栏右侧显示当前报文条数与状态，例如 `356 条 / 跟随记录等待中`。

#### `跟随记录`（默认开启）

开启后 PD 分析与主监控**完全联动**：

- 仅在主监控记录时采集 PD 报文，未记录时报文直接丢弃、不进缓冲；
- 左侧的开始 / 暂停按钮同时控制主监控的记录；
- 两侧的清空互相联动，清空任意一侧都会同时清空图表与报文。

关闭后三者互不影响：PD 独立采集、独立暂停、独立清空。

### 报文列表

| 列 | 含义 |
| --- | --- |
| `#` | 序号 |
| `Elapsed` | 相对首帧的时间，精度到毫秒 |
| `SOP` | `SOP`（端到端）/ `SOP'`（到线缆芯片）等起始序列类型 |
| `Msg` | 消息类型徽章，按类别着色 |
| `ID` | Message ID（0–7 循环） |
| `Direction` | 角色方向徽章，如 `SRC → SNK`、`SRC ← SNK`、`SRC\|SNK → Plug` |
| `Obj` | 携带的 Data Object 个数 |
| `Rev V/I` | 该帧时刻仪表测到的电压 / 电流 |
| `Note` | 速览摘要 |

`Note` 列是快速定位协商过程的关键，几种典型内容：

```
Fixed: 5.0V 9.0V 12.0V 15.0V 20.0V SPR AVS: 9-15V@3.0A 15-20V@5.0A PPS: 5.0-21.0V
Position:1 Fixed:5.0V,3.0A
Position:7 PPS:8.0V,3.45A
0xFF00 Discover Identity REQ
```

即：Source_Capabilities 直接列出充电器广播的全部档位，Request 直接给出设备选了第几档、要求多少电压电流。

### 详情面板

点击任意报文行，详情面板把该帧拆成三层：

1. **原始数据** —— `SOP*`、`Msg Header` 与 `Data Object 0..N` 的十六进制值。
2. **报文头字段表** —— `Extended` / `Objects` / `Msg ID` / `Power Role` / `Spec Rev` / `Data Role` / `Msg Type`。
3. **每个 PDO / RDO 的位域表** —— 例如 `PDO 1 5.0V,3.0A FPDO 0x0A81912C` 展开为 `Supply Type`、`Dual-Role Power`、`USB Suspend Supported`、`Unconstrained Power`、`USB Communications Capable`、`Dual-Role Data`、`Unchunked Extended Messages Supported`、`EPR Capable`、`Peak Current`、`Voltage`、`Maximum Current` 等逐字段取值。

> **抓包建议：** 信息量最大的时刻是**插拔充电器的瞬间** —— 完整的 Discover Identity → Source_Capabilities → Request → Accept → PS_RDY 握手都在最初几十毫秒内完成。设备已经协商好之后再开始记录，只能看到周期性的 PPS 微调。

## POWER-Z 协议控制

连接 POWER-Z KM003C / KM002C 后，标题栏会显示 `协议控制` Tab。该页通过设备的虚拟串口执行
PDM、PDO 读取、PD/PPS/AVS 请求、QC/FCP/SCP/UFCS 检测与取消；实时电压、电流、功率读数仍来自
同一设备的 Bulk 采集流。命令执行期间可以点 `取消`，断开或 Bulk 重连会自动结束当前 PDM 会话。

维简设备不会显示这个 Tab，也不会发送任何控制命令。

## 设置页

点击标题栏右侧的齿轮按钮进入；macOS 上也可以按 ⌘, 或从应用菜单选「Settings…」。设置页左栏是主列表，右栏（宽屏时）是设备与关于信息。

### 外观

| 设置 | 控件 | 默认 |
| --- | --- | --- |
| `主题` | `跟随系统` / `浅色` / `深色` | 跟随系统 |
| `窗口风格` | `跟随平台` / `Windows 风格` / `macOS 风格`（仅 Windows / Linux） | 跟随平台 |
| `界面缩放` | 滑块，50% – 200% | 100% |

界面缩放会等比缩放整个界面（含图表与标题栏）。系统缩放偏大导致窗口拥挤时可调低。滑块在拖动结束时才应用，拖动过程中不会反复重排。macOS 的系统红绿灯不随界面缩放，标题栏会为它们保留固定的位置。

首次运行和重置配置后，主题随操作系统外观变化；已有主题选择会保留。窗口风格的「跟随平台」按平台选择标题栏样式，与深浅主题独立。macOS 使用系统原生红绿灯：全屏、平铺、最小化由系统按钮处理，双击标题栏空白处按「系统设置 › 桌面与程序坞」中的选择缩放或最小化，因此不显示窗口风格选项。

### 图表与记录

| 设置 | 控件 | 默认 |
| --- | --- | --- |
| `图表纵向余量` | `自动` / `自定义` + 百分比 | 自动（≈ 25%） |
| `记录电流方向` | 开关 | 关闭 |
| `单次记录上限` | 数值输入，64 – 8192 MB | 512 MB |
| `保留临时恢复文件` | 开关 | 开启 |
| `重置所有配置` | 按钮 | — |

- **图表纵向余量** —— 曲线顶部预留的空白比例，让曲线保持在中高位置而不贴顶。选 `自定义` 后可填 0 – 100 的百分比。
- **记录电流方向** —— 开启后，新记录或新导入的数据保留电流符号（正向为正、反向为负），侧栏用箭头指示方向；关闭时记录绝对值。**不改写已有数据**，导出跟随当前记录到的值。
- **单次记录上限** —— 按内存与 CSV 行大小估算，达到上限自动暂停；底栏显示预计剩余时间。
- **保留临时恢复文件** —— 记录时约每秒写入应用缓存。未正常结束的记录可在设置页恢复或删除；成功同步后的正常清空、导入或退出会清理临时文件，写入或同步失败时保留文件并提示错误。长期保存仍需显式导出 CSV。
- **重置所有配置** —— 恢复采样率、显示通道、界面缩放、自动暂停、温度服务等全部设置的默认值。只有确认写盘成功才会提示「已恢复默认设置」；`settings.json` 被杀毒软件或同步盘占用时改为报错，因为此时界面已经回到默认、重启后却会全部回滚。同一次故障期内只提示一次，不会随每个控件的自动保存反复刷屏。

### 设备

显示当前连接设备的 `VID` / `PID` / `SN`（来自设备枚举，不中断数据流）。

> 维简硬件的 USB 序列号是**生产批次日期**而不是单机编号，同批次的两台仪表会拿到相同的序列号。标题栏设备列表因此会带上 USB 端口，以便区分插在不同口上的同型号仪表。

### 关于

软件图标展示在版本号上方，下方是 `版本` / `许可证` / `仓库` 三行，以及第三方组件声明：uPlot (MIT) · Fluent System Icons (MIT)。

## 文件格式

### CSV

导出文件为 4 行元信息 + 1 个空行 + 表头 + 数据行：

```csv
SUM,1
TotalTime,="00:00:00.000"
SampTime(ms),250
DateTime,2026-08-23 00:15:42

Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W),Temp(°C),D+(V),D-(V),CC1(V),CC2(V),RelativeTime(s),Timestamp(ms),RecordingSegment,SampleInterval(ms),
="00:00:00.000",9.0991,0.0646,0.58820186,31.5,0.61,0.02,0.5,1.6,0,1787415342000,1,250,
```

- 选择 `不带温度` 导出时，表头与数据行中**没有 `Temp(°C)` 这一列**，其余列不变。
- 时间列写成 `="HH:MM:SS.mmm"` 的形式是为了让 Excel 按文本而不是日期解析。超过一天时前缀天数，形如 `="1.02:03:04.500"`。
- 数值列使用可往返的十进制文本，保留原始精度与电流符号，不按界面显示的小数位数截断。缺失值留空；设备的实际分辨率因通道和型号而异。
- `RelativeTime(s)` 保存精确相对秒，`Timestamp(ms)` 保存绝对时间戳；`RecordingSegment` 为可选列，用来区分录制段，暂停期间不积分。`SampleInterval(ms)` 保存逐点采样间隔，支持混合采样率。旧文件缺少这些尾列时仍可导入。
- 信号线列在数据缺失时留空，因此**不含这四列的旧文件仍可导入** —— 导入逻辑按表头名匹配列，不依赖列序。

### PD 捕获

导出为 JSON 信封：

```json
{
  "app": "laPower",
  "kind": "pd-capture",
  "version": 2,
  "exportedAt": "2026-08-23T00:15:42.000Z",
  "entries": []
}
```

`version: 2` 是当前的紧凑格式；`version: 1` 的旧树形格式仍可导入。导入时会校验 `kind` 与 `version`，不匹配会给出明确报错而不是静默失败。

导入的报文与实时采集的报文使用不同的日志代号（generation），因此导入一份历史捕获不会和当前实时流互相串号。

## 常见问题

### 设备未被识别

- 确认设备已在下拉框中出现 —— 点击刷新按钮重新扫描。
- 枚举按厂商 VID `0x0716` 进行，所以只要是维简设备就应该出现。如果完全不出现，检查数据线是否只有供电线芯、以及是否插在了仅供电的端口上。
- 尝试重新插拔。

### 连接失败

- 检查设备是否被其他上位机程序占用（同一 HID 接口不能被两个程序同时独占打开）。
- 关闭其他 WITRN 上位机后重试，或重启本应用。

### Linux 下扫不到任何设备

这几乎总是**权限问题**而不是识别问题：`hidapi` 需要打开 `/dev/hidrawN`，默认只有 root 有权限，普通用户运行时会「启动正常但设备列表为空」且没有任何报错。

解决方法见 [开发与构建 · udev 规则](DEVELOPMENT.md#udev-规则必需)。

### macOS 上长时间无人值守记录

- 记录中（`记录:` 显示进行中）本应用会阻止 Mac 自动睡眠，屏幕仍按系统设置熄灭；暂停或停止记录后恢复正常睡眠。只连接、不记录时不阻止睡眠。
- 窗口最小化、被遮挡或切到其他桌面时采集照常进行。
- 合上笔记本盖子（未接外接显示器）或手动选择「睡眠」仍会让 Mac 睡眠，USB 读取随之中断；长时间测试请保持开盖或接外接显示器。

### 数据显示异常

- 确认设备型号在[支持列表](../README.md#-支持的设备)中。显示为「未知 WITRN 设备」的型号能否正常读数取决于其固件是否使用相同的报告布局。
- 解析器会拒绝帧头错误或电压 / 电流明显超出物理范围的报告，所以异常固件通常表现为「连上了但没有数据」而不是显示错误数值。

### 温度一直是 `--`

- 温度源默认是 `外部`（TCP）。如果你要用仪表自带的温度，需要在 `温度服务` 浮出面板把 `来源` 切到 `本机`。
- 用外部 TCP 源时，检查 IP 与端口、以及服务器发送的是否为纯数字加换行。详见 [外部温度服务](TEMPERATURE.md)。
- 温度字节偏移只在部分型号上验证过。温度越界时解析器按「无温度」处理，不会因此丢弃整帧数据 —— 所以电压电流正常而温度恒为 `--` 是可能的。
