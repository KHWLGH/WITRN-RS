# WITRN-RS v0.2.0

WITRN USB 电表（C4/C5/U3/K2）的桌面上位机。本版是一次界面与性能的大改：整个前端重构为 Fluent 2 多 Tab 工作区，新增 PD 协议分析工作区、浅色主题，并把高频采集下的图表流畅度问题系统性解决掉。

## 下载

| 文件 | 说明 |
| --- | --- |
| `WITRN-RS_0.2.0_x64-setup.exe` | Windows x64 安装程序（NSIS，推荐） |
| `WITRN-RS_0.2.0_x64_en-US.msi` | Windows x64 MSI（适合批量/静默部署） |

需要 Windows 10 1803+ 与 WebView2 运行时（Win11 及多数 Win10 已内置，安装程序会在缺失时引导安装）。安装包未做代码签名，SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」即可。

## 主要变化

### 界面重构为 Fluent 2 多 Tab 工作区
仿 Office Ribbon 的单页布局（默认窗宽就横向溢出）换成 **监控 / PD 分析 / 设置** 三个工作区 Tab，每个工作区自带其功能相关的设置。设备连接区常驻自定义标题栏，任何页面都能快速连断；底部新增全局状态栏显示记录状态、点数与连接状态。

配套的还有一整套设计令牌层（原始色 → 语义角色 → 组件旋钮），配色对齐官方 Fluent UI Theme Colors，图表曲线色与图例、复选框、卡片强调条同源。

### 新增 PD 协议分析工作区
左列表 + 右详情分栏：报文列表带时间戳、SOP/SRC/SNK/CBL 徽章与 PDO/RDO 速览，点击行在右栏渲染完整逐字段解码树（含原始位与位置），↑/↓ 键导航。支持暂停缓冲、按消息类型过滤、隐藏 GoodCRC、自动滚动，以及捕获文件的导入 / 导出（版本化 JSON，v1 文件仍可导入）。

「跟随记录」开启时，PD 采集按钮直接就是主监控的记录开关，两侧的清空也互相联动并各带确认弹窗。

### 浅色主题与界面缩放
主题三档：深色 / 浅色 / 跟随系统（默认深色，已有配置不受影响）。跟随系统时监听 `prefers-color-scheme`，OS 外观变化即时切换。另新增 50%–200% 的界面缩放（步进 5%），主路径走 Tauri `setZoom`，不可用时 CSS 回退。

### 实时采集与图表流畅度
- HID 读线程与 IPC 发射线程拆开，`pd-data` 改为按帧合并的批量事件（报文一条不丢），采样率改 `AtomicU64`，读循环不再每圈抢锁
- 主曲线改为可扩容 `Float64Array` 列（uPlot 零拷贝视图），图表数据单份列式存储，去掉各通道的双份拷贝
- 可见窗口超过 2× 宽度后改送增量 min/max 像素桶，悬停仍二分回原始点；绘制按上一帧耗时做预算
- Windows WebView2 开启 GPU 栅格，图表 canvas 提到合成层
- PD 记录与图表记录都去掉了 2000 条 / 定长封顶，改为可增长存储 + 虚拟列表

### 数据模型扩展
- **D+/D-/CC1/CC2 四路信号线**：后端一直在推、前端此前丢弃，现在侧栏有实时卡、可叠加到图表、CSV 导出追加四列（导入按表头名定位，新旧格式兼容）
- **记录电流方向**（默认关）：开启后正向为正、反向为负，电流轴自动向负半轴扩展；侧栏数值恒为幅值、方向以箭头指示；能量积分与自动暂停阈值恒按幅值
- **设备信息**：产品名、批次序列号与端口无关的稳定指纹（录制中禁用，该命令会暂停数据流约 2 秒）

### 图表可读性
四条 Y 轴共用一个等分数并各自量化量程，第 i 条刻度在四轴上落到同一像素行；网格收敛为主/次两级不透明令牌。Y 轴标题从竖排贴边改到轴顶横向放置，绘图区变宽。纵向余量可配置（默认自动预留约 25% 顶部空白）。

### 窄窗口适配
按各区域 min-content 实测分档收紧：<1080 收紧间距与侧栏，<980 命令栏图标化，高度 <620 时间轴收为 64px。文字始终 13px 不缩放。最小窗口 900×600 下侧栏不再出现滚动条。

## 值得注意的修复

- **休眠 / NTP 校时不再把能量积分算爆**：相对时间轴遇到超过约 2 秒的空档只前进一个采样间隔
- **点「开始记录」后立刻插充电器不再丢 PD 握手**：先等后端打开采集再置本地标志，并按 seq 补洞
- **U3 的 PID `0x5044` 变体**现在能正确识别（此前显示「未知 WITRN 设备」）
- **HID 超时不再假装还连着**：读到过报告之后连续 2 秒读空视为拔线
- 节流窗口保留峰值电流，尖峰不再被 last-wins 吃掉
- 电流略超 ±10 A 不再丢整帧（有效范围放到 ±20 A）
- 不完整的 EPR Source Capabilities 不再覆盖 `last_pdo`
- Hard Reset / Cable Reset 的 SOP 字节按仪表 32 步进编码识别
- Structured VDM Version 2.1 不再被标成 Reserved
- 读取设备身份时若用户中途另连/断开，不再盖掉新连接
