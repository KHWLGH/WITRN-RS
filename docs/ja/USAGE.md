## 言語の選択

「設定 → 外観 → 言語」で、システムに従う、简体中文、繁體中文、English、日本語を選択できます。変更は即座に反映・保存され、接続、記録、データ、グラフ範囲、フィルター、選択中のメッセージを保持します。設定をリセットすると自動選択に戻ります。

Linux では LC_ALL → LC_MESSAGES → LANG の順で最初の空でない値を使用し、Windows／macOS ではネイティブのシステム locale を取得します。取得できない場合は WebView の優先言語を使い、最終的に英語へフォールバックします。地域よりも文字体系を優先し、Hans は簡体字、Hant は繁体字を選びます。それ以外では CN／SG と地域なしの zh は簡体字、TW／HK／MO は繁体字、ja は日本語、それ以外（C／POSIX を含む）は英語になります。大文字小文字、アンダースコア、文字コード・修飾子の接尾辞を正規化します。手動選択は自動検出より優先されます。

```bash
LANG=en_US.UTF-8 ./laPower.AppImage
LC_ALL=ja_JP.UTF-8 ./laPower.AppImage
env -u LC_ALL LC_MESSAGES=zh_TW.UTF-8 LANG=en_US.UTF-8 ./laPower.AppImage
```

## 画面の概要

ウィンドウは **タイトルバー**（タブと接続欄）、**ワークスペース**（現在のタブ）、**ステータスバー**の 3 層です。

### タイトルバー

タイトルバーはタブバーも兼ねます。モニター、PD 分析、設定は常に表示し、POWER-Z に接続するとプロトコル制御を追加します。

| タブ | 内容 |
| --- | --- |
| `モニター` | リアルタイム測定値、グラフ、記録、インポート／エクスポート |
| `PD 分析` | USB-PD メッセージ一覧とフィールドごとのデコード |
| `プロトコル制御`（POWER-Z のみ） | PDM、PDO、プロトコル検出、電圧要求 |
| `設定`（歯車） | 外観、グラフと記録、デバイス VID/PID/SN、このアプリについて |

右側の**常設接続欄**にデバイス選択、更新ボタン、状態に応じた `接続`／`切断` ボタンがあります。どのタブからも操作でき、モニターへ戻る必要はありません。未接続時は `接続`、接続後は同じボタンが `切断` になります。

デバイス名の形式：

```text
WITRN K2                                    USB ポートを取得できない場合
WITRN K2 (USB 4-4)                          USB トポロジーポートを取得した場合
WITRN K2 (USB 4-4) [インターフェイス 0 / Usage 0xFF00]   同一デバイスに複数の HID インターフェイスがある場合
```

インターフェイスの接尾辞は物理デバイスの絞り込み後も複数の HID インターフェイスが残る場合だけ表示します。不明な PID の WITRN は `不明な WITRN デバイス (0716:XXXX)` と表示します。

### ステータスバー

下部には `記録:`（記録状態、**クリックして開始・一時停止可能**）、`時間:`（記録の累積時間）、`サンプル:`（取得頻度）、`点数:`（取得した総点数）、右端に接続状態（`接続済み`／`未接続`）を表示します。未接続時に `記録:` をクリックしても記録は開始しません。

## モニターワークスペース

### コマンドバー

| 操作 | 説明 |
| --- | --- |
| `記録開始`／`記録を続行`／`記録を一時停止` | データなしでは `記録開始`、既存・インポート済みデータがあると `記録を続行`、記録中は `記録を一時停止`。続行では既存データを消さず現在のタイムラインへ追加します |
| `サンプルレート` | 下の表から選択 |
| `CSV をエクスポート` | `温度なし`／`温度あり`。コマンドバーが狭い場合、インポート・リセットとともに右端の `⋯` メニューへ移動します |
| `CSV をインポート` | 以前の CSV を読み込み、最後の時刻から記録を続行できます |
| `リセット` | グラフを消去し、統計・積算電力量をリセット |
| `⋯` | 幅不足時に表示し、エクスポート・インポート・リセットをまとめます |
| `表示` | チャンネル表示のフライアウトを開きます |
| `自動一時停止` | 切り替えボタンと、設定フライアウトを開く歯車 |
| `温度サービス` | 切り替えボタンと設定用歯車。[外部温度サービス](TEMPERATURE.md)を参照 |

サンプルレートのプリセット（間隔は実際のミリ秒値で、CSV の `SampTime(ms)` にも使用）：

| 表示 | 間隔 |
| --- | --- |
| `100 サンプル/秒` | 10 ms |
| `10 サンプル/秒` | 100 ms |
| `4 サンプル/秒` | 250 ms（既定） |
| `2 サンプル/秒` | 500 ms |
| `1 サンプル/秒` | 1000 ms |
| `0.2 サンプル/秒（5 秒に 1 回）` | 5000 ms |
| `0.1 サンプル/秒（10 秒に 1 回）` | 10000 ms |

POWER-Z KM003C／KM002C を選ぶと `1000 サンプル/秒`（1 ms）を追加します。AdcQueue を使い、サンプルはデバイスの 1 kHz 時間基準を持ち、温度は並行する ADC スナップショットで補います。認証やファームウェアが高速キューに対応しない場合は `100 サンプル/秒` に戻り、理由を通知します。WITRN HID は常に 10 ms 以上の間隔です。

バックエンドの `set_sample_rate` は 1–60000 ms の任意値を受け付け、実際の下限はデバイスに依存します。CSV インポートは各点の間隔、要約の間隔、または時刻列からの推定を使い、保存済みのサンプルレートを変更しません。選択欄は次のライブ記録用の間隔を示します。

サンプルレートは**電力量の積分で除外する空白時間**にも影響します。隣接点の間隔が `max(2 秒, 8 × サンプリング間隔)` を超える場合、その区間は積分しません（スリープ、NTP 補正、取りこぼしなど）。毎秒 0.2 回／0.1 回では許容間隔も 40 秒／80 秒へ広がり、通常の低速取得を欠落と判定しません。

### 測定値カード

左パネルは幅 200–360 px（既定 250 px）に変更でき、右端の仕切りをドラッグすると保存します。電圧・電流・電力・温度の 4 カードは共通構造です。

- タイトルはチャンネル色の丸と名称。
- 現在値を囲む角丸の**水平レベルバー**。背景は淡く、塗りは同じチャンネルの強い色で、セッション中の観測最大値から 1-2-5 ステップで自動レンジを決め、左から右へ埋まります。中央の大きな数値はバーの大部分を占め、通常の文字色を使います。
- 3 列の統計：`最小`／`平均`／`最大`（温度は `最低`／`平均`／`最高`）。

その他の動作：

- **電流** — 「電流の方向を記録」が有効な場合、数値の前に方向矢印を表示します。
- **温度** — 取得元がない場合はカードを非表示にし、欠損値は `--` です。`デバイス` を使う場合、計器の切断・抜去で取得元を解除し、値を `--` に戻し、`温度サービス` ボタンをリセットして `取得元` を再選択可能にします。`外部` の TCP 接続は計器の接続状態から独立しています。
- **積算電力量（Wh）・積算容量（mAh）** — 計器内部のカウンターではなく、ソフトウェアでサンプルを積分します。各行に自動レンジの小型水平バーがあります。**ゼロに戻すのは `リセット` のみ**です。一時停止後の続行では積算値を保持し、停止時間は積分しません。`max(2 秒, 8 × サンプリング間隔)` を超える空白も除外します。
- **信号線** — D+ / D- / CC1 / CC2 の各電圧に名称・値・小型水平バーを表示します。表示は小数 2 桁で、実際の分解能はデバイスに依存し、WITRN CC1／CC2 は 0.1 V です。

データがないグラフには「デバイスを接続して記録を開始してください」と表示し、最初の点が記録されると消えます。

### `表示` フライアウト

- 主曲線 `電圧`／`電流`／`電力`／`温度` に表示チェックと**塗りの不透明度**があります（0 = 無効、1–100 = 有効、既定 15）。
- `D+ / D-` は電圧軸を共有する 2 本の信号曲線を追加します。既定は無効です。
- `CC1 / CC2` も電圧軸を共有し、既定は無効です。
- `選択範囲のみ` を有効にすると、カードの最小・最大・平均、積算電力量・容量をタイムラインの選択範囲だけから計算します。既定は無効です。非有限値（インポート CSV の空欄、`NaN`、`Inf`）は最小・最大・平均から除外し、平均のツールチップに除外数を示します。`範囲` の「(N 点)」は計算対象の有効値数ではなく元の行数です。

### `自動一時停止` フライアウト

無人テストで、選択した測定値がしきい値未満の状態を一定時間維持すると記録を一時停止します。

| 項目 | 値 |
| --- | --- |
| `条件` | `なし`（既定、無効）／`電圧 <`／`電流 <`／`電力 <` |
| `しきい値` | 数値。単位は条件に合わせて切り替わります |
| `継続時間` | 秒。この時間連続して条件を満たすと発動します |

### グラフとタイムライン

最大 8 曲線を 4 本の Y 軸、**電流（A）**、**電圧（V）**、**電力（W）**、**温度（°C）**に表示し、目盛りを厳密に揃えます。D+ / D− / CC1 / CC2 は電圧軸を共有します。

- **ツールチップ** — ホバーで全チャンネルの値と相対時刻（`HH:MM:SS.d`）を表示します。
- **凡例** — チャンネル名をクリックして一時的に非表示にします。
- **タイムラインナビゲーター** — 下部の縮小グラフの両端ハンドルで範囲を選び、中央の強調範囲をドラッグすると幅を保って移動します。中央に `時間:` と点数を表示します。
- **ホイールによる横方向ズーム** — メイングラフでカーソル時刻を中心にズームします。上・前方向で拡大、下・後方向で縮小します。記録中、右端が最新点に接していれば同じ時間幅で追従し、履歴を表示していればその範囲に固定します。スライダーも連動し、一時停止後に続行しても現在の範囲を保持します。
- 密なデータは増分 min/max ピクセルバケットで描画しますが、全データは列形式で保持します。ホバーは二分探索で元の値を参照します。履歴は高 DPI を含むキャンバスの実ピクセル解像度で詳細を保ち、ドラッグ中と終了後は同じ投影を使います。1 ピクセルあたり 1 サンプル以下まで拡大すると、元の点と範囲両端の隣接点を表示します。

毎秒 1000 回の取得では自動描画は通常約 20 fps、負荷が高いと約 10 fps になります。ハンドル、範囲移動、ホイール、キーボード操作は独立して更新し、操作終了時に最終範囲を確定します。毎秒 100 回で正常に描画できる場合、履歴が長いだけで一定の低い更新頻度にはしません。更新頻度は表示だけに影響し、サンプル・CSV・統計・積分はすべて保持します。記録と履歴描画の予算は独立しており、遅い履歴フレームは一時的に塗りを切ってピクセル列描画にしても、曲線の詳細を保ちます。

## PD 分析ワークスペース

### コマンドバー

| 操作 | 説明 |
| --- | --- |
| `記録開始`／`一時停止` | 連動モードでは記録を開始・一時停止。独立モードでは一覧更新だけを一時停止し、バックグラウンドで取得を続けます |
| `クリア` | メッセージ一覧を消去 |
| `エクスポート`／`インポート` | PD キャプチャ JSON の保存・読み込み |
| `メッセージ種別で絞り込み…` | メッセージ種別名で一覧を絞る入力欄 |
| `GoodCRC を非表示` | 半数以上を占めやすいリンク層確認フレームを隠して読みやすくします |
| `自動スクロール` | 新規メッセージで末尾へ移動 |
| `記録と連動` | モニターとの同期。下記参照 |
| 分割方向 | 幅 ≥ 1400 px では左右分割（一覧約 55%／詳細約 45%）が可能。設定を保存し、狭いウィンドウでは上下分割に戻ります |

右側に件数と状態を表示します。例：`356 件 / 記録待ち`。

#### `記録と連動`（既定で有効）

有効時は PD 分析とモニターが**完全に連動**します。

- モニターの記録中だけ PD を取得し、それ以外のメッセージはバッファへ入れず破棄します。
- 左の開始・一時停止ボタンはモニターの記録も操作します。
- どちらをクリアしてもグラフとメッセージの両方を消去します。

無効時は PD の取得・一時停止・クリアが独立します。

### メッセージ一覧

| 列 | 意味 |
| --- | --- |
| `#` | 番号 |
| `経過時間` | 最初のフレームからの相対時間、ミリ秒精度 |
| `SOP` | `SOP`（端点間）、`SOP'`（ケーブルチップ宛て）などの開始シーケンス |
| `Msg` | 種別に応じて着色したメッセージバッジ |
| `ID` | Message ID（0–7 で循環） |
| `方向` | 役割・方向：`SRC → SNK`、`SRC ← SNK`、`SRC\|SNK → Plug` |
| `Obj` | Data Object の数 |
| `Rev` | USB-PD 仕様のリビジョン |
| `V/I` | 計器の最新電圧・電流サンプル。メッセージと同時刻とは限りません |
| `概要` | 要約 |

`概要` はネゴシエーションの位置を探す手掛かりになります。例：

```text
Fixed: 5.0V 9.0V 12.0V 15.0V 20.0V SPR AVS: 9-15V@3.0A 15-20V@5.0A PPS: 5.0-21.0V
Position:1 Fixed:5.0V,3.0A
Position:7 PPS:8.0V,3.45A
0xFF00 Discover Identity REQ
```

Source_Capabilities は充電器の全プロファイルを示し、Request は選択位置と要求電圧・電流を示します。

### 詳細パネル

行をクリックすると 3 層で表示します。

1. **生データ** — `SOP*`、`Msg Header`、`Data Object 0..N` の 16 進値。
2. **ヘッダーフィールド** — `Extended` / `Objects` / `Msg ID` / `Power Role` / `Spec Rev` / `Data Role` / `Msg Type`。
3. **各 PDO／RDO のビットフィールド** — 例：`PDO 1 5.0V,3.0A FPDO 0x0A81912C` を `Supply Type`、`Dual-Role Power`、`USB Suspend Supported`、`Unconstrained Power`、`USB Communications Capable`、`Dual-Role Data`、`Unchunked Extended Messages Supported`、`EPR Capable`、`Peak Current`、`Voltage`、`Maximum Current` などに分解します。

> **キャプチャのヒント：** 最も有用なのは**充電器を挿抜する瞬間**です。Discover Identity → Source_Capabilities → Request → Accept → PS_RDY は最初の数十ミリ秒で完了します。ネゴシエーション後に開始すると、通常は周期的な PPS の微調整だけが見えます。

## POWER-Z プロトコル制御

POWER-Z KM003C／KM002C 接続時に `プロトコル制御` タブが表示されます。デバイスの仮想シリアルポートで PDM、PDO 読み取り、PD/PPS/AVS 要求、QC/FCP/SCP/UFCS 検出・中止を行います。リアルタイム電圧・電流・電力は同じデバイスの Bulk ストリームから取得します。実行中は `キャンセル` で中止でき、切断や Bulk 再接続で現在の PDM セッションは自動終了します。

WITRN ではこのタブを表示せず、制御コマンドも送りません。

## 設定画面

タイトルバーの歯車ボタンから開きます。macOS では ⌘, またはアプリケーションメニューの「Settings…」からも開けます。左が主な設定一覧、右（広いウィンドウ）がデバイス情報と「このアプリについて」です。

### 外観

| 設定 | 操作 | 既定 |
| --- | --- | --- |
| `テーマ` | `システムに従う`／`ライト`／`ダーク` | システムに従う |
| `言語` | `システムに従う`／`简体中文`／`繁體中文`／`English`／`日本語`。自動モードは実際の言語を表示 | システムに従う |
| `ウィンドウスタイル` | `プラットフォームに従う`／`Windows スタイル`／`macOS スタイル`（Windows / Linux のみ） | プラットフォームに従う |
| `UI の拡大率` | スライダー、50–200% | 100% |

グラフとタイトルバーを含む UI 全体を同じ倍率で変更します。OS の拡大率で窮屈になる場合は下げてください。ドラッグ終了時に適用するため、操作中に何度もレイアウトを変更しません。macOS の標準ウィンドウボタンは拡大縮小せず、タイトルバーに固定の領域を確保します。

初回起動と設定リセット後は OS の外観に従い、既存のテーマ選択は保持します。`プラットフォームに従う` は OS に応じたタイトルバーを選び、ライト・ダークとは独立しています。macOS では標準ボタンでフルスクリーン、タイル表示、最小化を操作します。タイトルバーの空白をダブルクリックしたときの動作は「システム設定 › デスクトップと Dock」に従うため、ウィンドウスタイルの選択は表示しません。

### グラフと記録

| 設定 | 操作 | 既定 |
| --- | --- | --- |
| `グラフ上部の余白` | `自動`／`カスタム` と百分率 | 自動（約 25%） |
| `電流の方向を記録` | 切り替え | 無効 |
| `記録容量の上限` | 数値入力、64–8192 MB | 512 MB |
| `一時復元ファイルを保持` | 切り替え | 有効 |
| `すべての設定をリセット` | ボタン | — |

- **グラフ上部の余白** — 曲線の上に余白を残し、上端に張り付かないようにします。`カスタム` は 0–100% です。
- **電流の方向を記録** — 新しい記録・インポートで符号を保持し（順方向が正、逆方向が負）、矢印を表示します。無効時は絶対値を記録します。**既存データは書き換えず**、エクスポートは記録値を使います。
- **記録容量の上限** — メモリーと CSV 行サイズから推定し、上限で一時停止します。下部に推定残り時間を表示します。
- **一時復元ファイルを保持** — 約 1 秒ごとにキャッシュへ書き込みます。未完了記録を設定から復元・削除できます。正常なクリア・インポート・終了では同期成功後に削除し、書き込み・同期失敗時は保持してエラーを通知します。長期保存には CSV エクスポートが必要です。
- **すべての設定をリセット** — 言語、サンプルレート、表示チャンネル、UI の拡大率、自動一時停止、温度サービスなどを既定に戻します。ディスク保存に成功してから通知します。ウイルス対策や同期ソフトが `settings.json` を占有するとエラーになります。この場合、画面では戻っていても再起動で元に戻るためです。同じ障害の間は 1 回だけ通知し、各操作の自動保存で繰り返し表示しません。

### デバイス

接続デバイスの列挙情報 `VID`／`PID`／`SN` を、データストリームを止めずに表示します。

> WITRN の USB シリアル番号は個体番号ではなく**製造バッチの日付**です。同じバッチの計器は同じ番号を持つため、タイトルバーに USB ポートを付けて区別します。

## ファイル形式

### CSV

4 行のメタデータ、空行、ヘッダー、データ行の順です。

```csv
SUM,1
TotalTime,="00:00:00.000"
SampTime(ms),250
DateTime,2026-08-23 00:15:42

Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W),Temp(°C),D+(V),D-(V),CC1(V),CC2(V),RelativeTime(s),Timestamp(ms),RecordingSegment,SampleInterval(ms),
="00:00:00.000",9.0991,0.0646,0.58820186,31.5,0.61,0.02,0.5,1.6,0,1787415342000,1,250,
```

- `温度なし` ではヘッダー・データの **`Temp(°C)` 列を除去**し、他の列は変わりません。
- 時間を `="HH:MM:SS.mmm"` にして Excel に日付ではなく文字列として読ませます。1 日を超えると `="1.02:03:04.500"` のように日数を付けます。
- 数値は往復可能な十進表記で元の精度と電流の符号を保持し、UI の桁数には切り詰めません。欠損値は空欄です。実際の分解能はチャンネルとモデルに依存します。
- `RelativeTime(s)` は精密な相対秒、`Timestamp(ms)` は絶対時刻です。任意の `RecordingSegment` は記録区間を区別し、停止中の積分を除外します。`SampleInterval(ms)` は各点の間隔を保持し、混在したレートに対応します。末尾列のない旧ファイルも読み込めます。
- 信号線の欠損値は空欄で、**4 本の信号線列がない旧ファイルも読み込めます**。列順ではなく名前で照合します。

### PD キャプチャ

JSON エンベロープで保存します。

```json
{
  "app": "laPower",
  "kind": "pd-capture",
  "version": 2,
  "exportedAt": "2026-08-23T00:15:42.000Z",
  "entries": []
}
```

`version: 2` は現在のコンパクト形式で、旧ツリー形式の `version: 1` も読み込めます。`kind` と `version` を検証し、不一致なら明示的なエラーを表示します。

インポートとライブ取得はログの generation を分けるため、履歴の ID とライブストリームの ID が混ざりません。

## よくある質問

### デバイスが認識されない

- 更新ボタンで再スキャンし、選択欄に出るか確認してください。
- WITRN は VID `0x0716` で列挙するため表示されるはずです。出ない場合は充電専用ケーブル・ポートでないか確認します。
- 挿し直してください。

### 接続に失敗する

- 他の計器アプリが使用中でないか確認します。同一 HID インターフェイスを 2 アプリが同時に排他的に開くことはできません。
- 他の WITRN アプリを終了して再試行するか、laPower を再起動します。

### Linux でデバイスが見つからない

通常は**権限の問題**です。`hidapi` は `/dev/hidrawN` を開く必要があり、既定では root のみ許可されます。一般ユーザーでは正常起動しても一覧が空で、エラーが出ないことがあります。

[開発とビルド · udev ルール](DEVELOPMENT.md#udev-ルール必須)を参照してください。

### macOS で無人の長時間記録を行う

- 記録中はシステムのアイドルスリープを防止します。画面は通常どおり消灯し、記録の一時停止・停止後はスリープ設定に戻ります。記録せず取得するだけの場合は OS のスリープ設定に従います。
- 蓋を閉じる操作や手動のスリープは引き続き有効です。記録中は避けてください。
- macOS 14 以降では、最小化・非表示・他のウィンドウによる遮蔽でも取得を継続します。macOS 12–13 では WKWebView のバックグラウンド制限を解除できないため、長時間記録中はウィンドウを表示してください。

### 測定値が異常・表示されない

- [対応デバイス](../../README.ja.md#-対応デバイス)を確認してください。不明な WITRN は互換のレポート構造を使うファームウェアのみ対応します。
- パーサーは不正なヘッダーや物理範囲を大きく超える電圧・電流を拒否するため、異常なファームウェアでは通常、誤った数値より「接続済みだがデータなし」になります。

### 温度が `--` のまま

- 既定の取得元は `外部`（TCP）です。計器の温度は `温度サービス` の `取得元` を `デバイス` にしてください。
- TCP は IP、ポート、純粋な数値と改行の送信を確認します。[外部温度サービス](TEMPERATURE.md)を参照してください。
- 温度バイト位置は一部モデルだけで検証しています。範囲外の温度は測定フレーム全体を捨てず欠損として扱うため、電圧・電流が正常でも温度だけ `--` の場合があります。
